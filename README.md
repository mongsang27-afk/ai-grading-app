# 서·논술형 채점 도구

2회고사 대비 서·논술형 3세트(사회적 촉진과 억제 / 정전기 / 인공 지능의 그림)의 답안을 채점합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일

| 파일 | 역할 |
|---|---|
| `rules.py` | 세트별 채점 규칙. **기준을 고칠 때는 이 파일만 수정합니다.** |
| `grader.py` | 판정 엔진. 규칙을 해석해 점수와 근거를 만듭니다. |
| `app.py` | 화면. 개별 채점 / 일괄 채점 / 채점 기준 보기 세 모드. |
| `sample_answers.csv` | 일괄 채점 서식 예시 |

## 판정 순서

순서를 바꾸면 오검출이 생깁니다.

0. **안전 표현 마스킹** — `집중`을 `집`으로 잡는 일을 막습니다.
1. **금칙어** — 지문에서 부정된 선택지(예: 세트1 ㉡의 `집에서`)
2. **교차 오염** — 다른 개념의 특성을 끌어다 쓴 경우(예: 세트2 ㉠에 `흐르는 물`)
3. **결론 방향** — 조건이 요구한 결론과 반대인 경우(예: 세트3 ㉢의 `가치가 없다`)
4. **필수군** — 핵심군이 비면 부분 점수 없이 오답
5. **부분 인정** — 부가 요소 누락분만 감점

## 문항별 자동화 범위

- **문항 1** 완전 자동. 정답 집합이 닫혀 있습니다.
- **문항 2** 두 단계 자동. ① 괄호 명칭 추출 ② 그 방법의 특성이 문장 구조에 실제로 드러나는지 확인. 명칭이 없어도 특성이 드러나면 내용 점수를 인정하고, 괄호 표기 조건 미이행분만 명칭 점수 절반을 감점합니다(사이드바에서 끌 수 있음).
- **문항 3** 자동 채점하지 않습니다. 필수 요소 누락과 장면 1 복사만 1차로 걸러 내고, 최종 판정은 교사가 합니다.

## 규칙 수정 예

세트1 ㉡에서 `집에서`를 오답이 아니라 부분 인정으로 바꾸려면 `rules.py`에서 해당 항목을
`forbidden`에서 빼고 `partial`로 옮기면 됩니다. 엔진은 고칠 필요가 없습니다.
